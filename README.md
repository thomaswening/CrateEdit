# CrateEdit

A metadata editor for DJ music collections (MP3 and WAV, Windows and macOS). Edits are staged first and only written to files when you apply them, with conflict detection against external changes (Rekordbox, Serato, Traktor) and crash-safe writes.

Status: planning. See the [requirements](docs/requirements.md), [architecture](docs/architecture.md), [roadmap](docs/roadmap.md) and [development process](docs/development.md).

## Use at your own risk
CrateEdit writes to your audio files. It is provided as is, without warranty of any kind. Back up your collection before using it. Releases are not code-signed, so Windows and macOS will warn on first launch.
